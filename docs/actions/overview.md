title: What are Actions?
sidebar_label: Definition
---

Actions are the operations that are performed when a trigger occurs. An action defines what should happen - for example turning a device on or off, running a scene, controlling a device group of devices, activating an alarm or sending a notification. By choosing an action, you specify the exact outcome that will be executed automatically.

**Actions have several types**

| **Action type**    | **Contains**                                                                                                                |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| **_Device_**       | You choose a device and actions to apply to it (on, off)                                                                    |
| **_Notification_** | Could be activity log, Alexa notification, alert notification, email notification, push notification                        |
| **_Scene_**        | You choose a scene and apply scene actions - disable, enable, runDo, toggle, trigger                                        |
| **_Group_**        | You use a device group (multiple same-type devices combined) so one command is applied to all devices in that group at once |
| **_Alarm_**        | You set an alarm when a trigger fires (i.e., when an armed zone detects an event like motion or door/window opened)         |
