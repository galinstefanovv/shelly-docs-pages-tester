# Notification Action

A notification is an alert message generated by a device, Scene, Alarm or Script to inform you that a specific event has occurred. Notifications help you stay aware of important changes in your smart environment, whether they relate to security, safety or automation behavior.
Notifications can be triggered manually (from a script) or automatically (from a device condition or scene execution).

## Why Notifications matter

#### Security

Notifications help you react quickly to unexpected activity:

- **Motion detected.**
- **Door or window opened.**
- **Alarm triggered.**

#### Safety

With compatible sensors, notifications can warn you about conditions that may require immediate attention:

- **Overheating or abnormal temperature rise.**
- **Power overload.**
- **Water leak detection.**

#### Automation status

Notifications can confirm that your automations are working as intended:

- **Scene executed.**
- **AC turned off in Away mode.**
- **Custom script‑generated alerts.**

## Where Notifications appear

Depending on the notification type, alerts may appear in one or both of the following places:

- Push notifications on your mobile device.
- Activity Log inside the Shelly Smart Control app.

This ensures you can receive real‑time alerts and also review past events when needed.

## Notification types

When creating a notification in the script editor, you can choose from several predefined notification types. Each type has its own parameters:

| **Notification type**    | **Description**                                                                   |
| ------------------------ | --------------------------------------------------------------------------------- |
| **_Activity log_**       | Adds an entry to the app's Activity log. Useful for silent informational events   |
| **_Alexa notification_** | Sends a notification to Amazon Alexa                                              |
| **_Alert notification_** | Displays an alert inside the app. Used for warnings                               |
| **_Email notification_** | Sends an email to the configured address. Ideal for detailed or persistent alerts |
| **_Push notification_**  | Sends a push message to your mobile device. Best for real-time alerts             |

Each notification type includes configurable parameters such as title and message text.

```js
// --- Activity log
Shelly.logActivity(); // no delay
Shelly.logActivity("2s"); // message and 2 seconds delay
Shelly.logActivity("6m"); // message and 6 minutes delay

// --- Alexa notification
Shelly.sendAlexaNotification(); // no delay
Shelly.sendAlexaNotification("5s"); // message and 5 seconds delay
Shelly.sendAlexaNotification("1m"); // message and 1 minute delay

// --- Alert notification
Shelly.sendPhoneAlertNotification("My scene triggered!"); // no delay
Shelly.sendPhoneAlertNotification("My scene triggered!", "10s"); // message and 10 seconds delay
Shelly.sendPhoneAlertNotification("My scene triggered!", "1m"); // message and 1 minute delay

// --- Email notification
Shelly.sendEmailNotification("My scene triggered!"); // no delay
Shelly.sendEmailNotification("My scene triggered!", "20s"); // message and 20 seconds delay
Shelly.sendEmailNotification("My scene triggered!", "1m"); // message and 1 minute delay

// --- Push notification
Shelly.sendPhoneStandardNotification("My scene triggered!"); // no delay
Shelly.sendPhoneStandardNotification("My scene triggered!", "5s"); // message and 5 seconds delay
Shelly.sendPhoneStandardNotification("My scene triggered!", "2m"); // message and 2 minutes delay
```

This example demonstrates how to trigger every available notification type. The script performs the following actions:

- Sends immediate and delayed notifications.
- Schedules an email notification.
- Logs the script activity.
- Triggers an Alexa notification.
