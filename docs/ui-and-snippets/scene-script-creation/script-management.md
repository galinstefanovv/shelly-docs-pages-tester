The **All Scenes** screen provides a clear and intuitive way to manage your smart home automations. It brings all your custom scenarios together in one place, allowing you to quickly review what is active, make adjustments or create entirely new automations.

Each script is presented with its name, an ON/OFF toggle and visual indicators that show whether it is currently enabled or inactive. This organized layout helps you maintain full control over your environment and ensures that every automation works exactly the way you want it to.

<img src="/img/introduction/scenes-menu.png" alt="Scenes menu" width="600" />

<img src="/img/introduction/scenes-interface.png" alt="Scenes interface" width="600" />

The Script panel shows all elements that define how a scene works. It displays the triggers that start the automation, the devices involved and the active time during which the scene is allowed to run. The panel also includes any parameters used by the script, global variables shared across scenes, nested scenes that can be executed as part of the logic and device groups controlled together. This view gives you a complete overview of the scene’s behavior.
