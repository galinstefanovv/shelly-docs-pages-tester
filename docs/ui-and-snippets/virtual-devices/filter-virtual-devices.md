Once virtual devices have been created, they can be viewed directly from the All Devices page by applying the **Virtual Devices** filter. This allows you to quickly isolate and manage only the virtual devices.

**Applying the Virtual devices filter**

- Open the filter menu by selecting the filter icon located next to the search bar.
  The filter panel provides several filtering options for narrowing down the device list.
- Enable the Virtual Devices filter. When this option is selected, the device list is restricted to show only items classified as _Virtual Device_.
- The page updates automatically.
  Only virtual devices appear in the grid, each labeled with its name, current state and standard device controls.

**Purpose of the filter**

This helps you with:

- Quickly locate all virtual devices created through the components and device groups workflows.
- Manage or edit virtual devices without navigating through physical device entries.
- Validate that newly created virtual groups or components have been successfully exposed as virtual devices.
- Maintain a clean and organized overview.
