Navigate to the Script editor and open the script where you want to use the virtual device. Inside the right‑side panel of the Script editor, locate the **Snippets** button.

<img src="/img/virtual-devices/virtual-device-add-menu.png" alt="Script editor - Snippets" width="auto" height="500"/>

From the dropdown list that appears, choose **Device**. This option allows you to insert a reference to any device available in your Shelly account - including virtual devices.

A selection window will open, listing all devices associated with your account. Virtual devices appear in this list alongside physical devices. Select the virtual device you want to use. Once selected, the script editor will automatically insert the device reference into your script.

Virtual devices can be bound to a room, just like physical devices. Selecting a room filters the list of devices so that you only see devices assigned to that location.

<img src="/img/virtual-devices/add-virtual-device.png" alt="Add virtual device" width="600" />

## Adding a property

The process of assigning a property to a virtual component is performed through a dialog window. This dialog provides an interface that allows you to select the component, choose a property for it and define the value that should be applied when the action is executed.
