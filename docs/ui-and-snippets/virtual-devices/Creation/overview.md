# Create virtual devices

The creation and configuration of virtual devices in Shelly Control is performed from the _All Devices_ page. This interface allows you to attach virtual components to any Shelly device that is currently online and connected to the cloud.

## Opening the components section

Inside the device panel, you navigate to the Components section.
This section displays all existing components associated with the selected device.

**Each component can be:**

- Enabled or disabled.
- Edited (changing type‑specific settings).
- Deleted if no longer needed.
