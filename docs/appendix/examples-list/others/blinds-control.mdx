This script controls the blinds based on temperature and light levels. When the temperature reaches 26°C or higher, it checks how bright it is in the hallway. If the light level is above 40, the blinds close automatically.

This helps keep the room cooler by blocking sunlight only when it’s both hot and bright outside.
