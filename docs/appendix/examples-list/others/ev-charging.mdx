This script controls the electric vehicle charging station on a daily schedule. It turns the charger on every night at 10:30 PM and keeps it running overnight. Then, at 6:30 AM, it automatically turns the charger off. This setup is useful for charging the vehicle during off-peak hours without needing manual control.
