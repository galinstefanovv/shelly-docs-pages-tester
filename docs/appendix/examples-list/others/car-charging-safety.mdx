This script protects the electric vehicle charging station by monitoring the total power usage in the home. If the overall consumption exceeds 11,500 watts, the charger is turned off automatically.

Once turned off, it stays off for 30 minutes before it can turn back on again. This helps prevent overloading the electrical system while still allowing charging to resume later without manual action.
