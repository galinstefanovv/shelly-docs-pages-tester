In this script, if the room gets too warm, it tries to turn on the AC, but only if the window is closed. If the window is open, a phone notification is sent reminding you to close it first. Separately, whenever movement is detected in the room, the lights switch on automatically. It's handy for automating your home when you walk into a room and want things to handle themselves.
