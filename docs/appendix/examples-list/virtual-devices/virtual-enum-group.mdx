An enum property stores one value from a predefined list of options.
These options are configured when creating the virtual device.

**Typical uses:**

- Mode selectors (**e.g., Home, Away, Vacation**).
- Multi‑state logic (**e.g., Low, Medium, High**).
- Structured choices where only valid predefined states are allowed (**option_1, option_2, option_n**).
