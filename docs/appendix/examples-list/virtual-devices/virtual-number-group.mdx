A number property stores a numeric value (integer or decimal).

**Typical uses:**

- Counters (**e.g., number of events, retries, cycles**).
- Thresholds or limits used in scripts.
- Storing calculated values such as averages or timers (**11, 17, 13.14**).

:::tip
**The valid range for the number has no limit.**

It depends on what the user has set up.
:::
