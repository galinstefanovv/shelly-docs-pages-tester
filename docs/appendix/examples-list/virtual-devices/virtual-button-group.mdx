A button property represents button‑press events generated by a virtual component configured as a buttonGroup. Unlike continuous values **(number, text)** or stateful selections **(enum)**, button properties describe momentary actions performed by the user.

Each property becomes **true** only at the moment the corresponding press pattern occurs, allowing automations and scripts to react instantly to specific button interactions.
