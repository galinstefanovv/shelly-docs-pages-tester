This script automates the essential tasks for your washing machine. It cuts power 3 minutes after a flood sensor detects a leak, notifies you when a wash cycle finishes, and tracks how many cycles have run. It also reminds you to clean the washing machine filter every 30 cycles, with the check happening every Saturday morning at 9:00.
