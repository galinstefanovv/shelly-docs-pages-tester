This script keeps track of the usage of appliances in the office kitchen. It collects statistics for devices such as the microwave, coffee machine and kettle, which can be useful for managing supplies like coffee, tea and other consumables. The script also automates appliance availability based on working hours, turning devices on at the start of the day and off after office hours. This helps prevent potential issues or unnecessary power usage when no one is expected to be in the office.
