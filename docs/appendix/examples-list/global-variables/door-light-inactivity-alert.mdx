Every weekday evening, this script watches for signs of someone coming home between 7 PM and 8 PM, specifically whether a door was opened or a light was turned on. At 8 PM, it checks: if neither has happened, it sends an alert notification. It's a simple but useful check for monitoring an elderly relative or anyone who follows a predictable evening routine.
