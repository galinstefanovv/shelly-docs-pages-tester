This script helps you monitor your washing machine’s power usage on weekends (Friday, Saturday and Sunday) between 11 AM and 2 PM. If the machine uses a high amount of power for 5 minutes straight, you’ll receive a phone notification - and it will keep notifying you each time that happens. After 3 alerts, it stops and asks you to press a button to reset it. This is useful if you want to know when the wash cycle is done or if something seems to be running for too long.
