### Action Options

#### Delay

Any action property on any device can be given a **delay** instead of a plain value. Pass an object with `value` and `delay` fields — the action will execute after the specified time. The delay is expressed in seconds (`s`) or minutes (`m`).

```js
var light = Shelly.getDevice("x");
light.on = {
  value: true,
  delay: "5s"
};
```

#### Timeout

Actions on **relay** and **relayRoller** devices also support a **timeout** that automatically reverts the output to its previous state after the given time. Like delay, the value is expressed in seconds (`s`) or minutes (`m`).

```js
var toaster = Shelly.getDevice("x");
toaster.o1On = {
  value: true,
  delay: "30s",
  timeout: "6m"
};
```

### Button

#### `Triggers/Conditions`

#### Pressed Once

Fired when the device (button or relay) is pressed a single time.

```javascript
var button = Shelly.getDevice("x");
Shelly.setTriggerOnce(button, "o1PressedOnce", handler); 
```

#### Pressed Twice

Fired when the device (button or relay) is pressed twice in quick succession.

```javascript
var button = Shelly.getDevice("x");
Shelly.setTriggerOnce(button, "o1PressedTwice", handler); 
```

#### Pressed Three Times

Fired when the device (button or relay) is pressed three times in quick succession.

```javascript
var button = Shelly.getDevice("x");
Shelly.setTriggerOnce(button, "o1PressedThreeTimes", handler); 
```

#### Long Pressed

Fired when the device (button or relay) is held down.

```javascript
var button = Shelly.getDevice("x");
Shelly.setTriggerOnce(button, "o1PressedLong", handler);
```

#### Battery Level

Check whether battery of the device (button or sensor) is below a percentage threshold.

```javascript
var button = Shelly.getDevice("x");
Shelly.setTriggerOnce(button, "battery < 30", handler);
```

### Emeter

#### `Triggers/Conditions`

#### o1On

Fires when the device (emeter, relay or relayRoller) channel switches to оn.

```js
var emeter = Shelly.getDevice("x");
Shelly.setTriggerOnce(emeter, "o1On", handler);
```

#### o1Off

Fires when the device (emeter, relay or relayRoller) channel switches to оff.

```js
var emeter = Shelly.getDevice("x");
Shelly.setTriggerOnce(emeter, "o1Off", handler);
```

#### Voltage

Runs when the voltage on a specific channel matches the set value.

```js
var emeter = Shelly.getDevice("x");
Shelly.setTriggerOnce(emeter, "aVoltage == 100", handler);
```

#### Total Power

Triggers when the device (emeter, relay or relayRoller) total power reaches the current number.

```js
var emeter = Shelly.getDevice("x");
Shelly.setTriggerOnce(emeter, "powerConsumption == 100", handler);
```

#### Power

Starts when the device (emeter, relay or relayRoller) measured power goes below the given value.

```js
var emeter = Shelly.getDevice("x");
Shelly.setTriggerOnce(emeter, "aPower < 300", handler);
```

#### `Actions`

#### o1On

Turns the device (emeter, relay or relayRoller) output channel on.

```js
var emeter = Shelly.getDevice("x");
emeter.o1On = true;
```

#### o1Off

Turns the device (emeter, relay or relayRoller) output channel off.

```js
var emeter = Shelly.getDevice("x");
emeter.o1Off = true;
```

#### Toggle

Switches the device (emeter, light, relay or relayRoller) output to the opposite of its current state.

```js
var emeter = Shelly.getDevice("x");
emeter.o1Off = !emeter.o1Off;   // emeter, relay or relayRoller
```

```js
var light = Shelly.getDevice("x");
light.off = !light.off;   // light
```

### Light

#### `Triggers/Conditions`

#### On

Triggers when the light switches to the on state.

```js
var light = Shelly.getDevice("x");
Shelly.setTriggerOnce(light, "on", handler);
```

#### Off

Triggers when the light switches to the off state.

```js
var light = Shelly.getDevice("x");
Shelly.setTriggerOnce(light, "off", handler);
```

#### Brightness

Starts when the brightness level goes below the specified value.

```js
var light = Shelly.getDevice("x");
Shelly.setTriggerOnce(light, "brightness < 70", handler);
```

#### `Actions`

#### On

Turns the light on.

```js
var light = Shelly.getDevice("x");
light.on = true;
```

#### Off

Turns the light off.

```js
var light = Shelly.getDevice("x");
light.off = true;
```

#### Brightness

Sets the brightness level to the specified percentage.

```js
var light = Shelly.getDevice("x");
light.brightness = 40;
```

#### Temperature

Changes the color temperature to the given Kelvin value.

```js
var light = Shelly.getDevice("x");
light.temperature = 4000;
```

#### White

Adjusts the white channel intensity (same format for red, green, blue).

```js
var light = Shelly.getDevice("x");
light.white = 50;
```

### Relay Roller

#### `Triggers/Conditions`

#### Open

Fires when the device (relayRoller or door) opens.

```js
var relayRoller = Shelly.getDevice("x");
Shelly.setTriggerOnce(relayRoller, "open", handler);
```

#### Closed

Fires when the device (relayRoller or door) reaches the fully closed position.

```js
var relayRoller = Shelly.getDevice("x");
Shelly.setTriggerOnce(relayRoller, "closed", handler);
```

#### Stop

Fires when the roller stops moving.

```js
var relayRoller = Shelly.getDevice("x");
Shelly.setTriggerOnce(relayRoller, "stop", handler);
```

#### Set Position

Runs when the roller reaches the specified position percentage.

```js
var relayRoller = Shelly.getDevice("x");
Shelly.setTriggerOnce(relayRoller, "position == 30", handler);
```

#### `Actions`

#### Open

Moves the roller to the open position.

```js
var relayRoller = Shelly.getDevice("x");
relayRoller.open = true;
```

#### Closed

Moves the roller to the closed position.

```js
var relayRoller = Shelly.getDevice("x");
relayRoller.open = false;
```

#### Stop

Stops the roller immediately.

```js
var relayRoller = Shelly.getDevice("x");
relayRoller.stop = true;
```

#### Set Position

Sets the roller to the given position percentage.

```js
var relayRoller = Shelly.getDevice("x");
relayRoller.position = 45;
```
