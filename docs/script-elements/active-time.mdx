# Active time

Sets a time window when a script is allowed to run. Outside the window, the script wont't execute.

**You set an interval in which a script can be performed:**

- First, select a day(s) of the week using a checkbox (at least 1 day must be selected).
- Then a start and end time interval is selected (at least 1 minute).

:::important
You should specify a time interval; otherwise, the default one will be used: (00:00 - 23:59), (Monday - Sunday).
:::

:::info
`setActiveTime` defines a time window for the entire script. If the current time is outside that window, none of the script’s actions will run.

`checkActiveTime` is used inside a handler to check whether the current moment is within a specific time window. It returns true or false, allowing you to decide whether to run an action only when the time condition is met.
:::
