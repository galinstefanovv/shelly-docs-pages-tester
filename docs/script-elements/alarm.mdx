An alarm is a special type of scene that monitors one or more sensors and is created through the UI. They are not part of the scripting and cannot be created through scripts. Once an alarm exists, you can use it in the editor and control it through scripting.

**Alarms support three actions:**

- **enable** - Activates the alarm;
- **disable** - Deactivates the alarm;
- **toggle** - Switches between enabled and disabled states;
